Calculator Web Application

A responsive and interactive calculator application built using HTML, CSS, and JavaScript.
This project performs basic arithmetic operations with a clean and user-friendly interface.

Features
Addition, subtraction, multiplication, and division operations
Responsive and modern UI design
Interactive button-based input system
Real-time calculation display
Error handling for invalid expressions
Technologies Used
HTML5 – Structure of the application
CSS3 – Styling and layout design
JavaScript – Calculator functionality and logic
